# FS25_HelperPayroll

**FS25_HelperPayroll** is a Farming Simulator 25 gameplay realism mod that replaces the default AI helper wage behaviour with a more structured payroll-style system.

The aim of the mod is to make hired labour feel less like a generic game charge and more like a realistic farm staffing cost. Instead of relying entirely on the base game helper pricing, HelperPayroll can suppress the standard AI worker wage calculation and apply its own role-based pay logic.

This mod is intended to work alongside **FS25_HelperProfiles**, allowing named helpers to be associated with roles, skills, and pay grades such as general farm staff, skilled operators, or specialist contractors.

## Purpose

Farming Simulator helpers are useful, but the default wage model is limited for players who want a more realistic or roleplay-focused farm economy.

**FS25_HelperPayroll** is designed to provide:

- More realistic helper wage handling
- Role-based worker pay rates
- Support for different worker skill levels
- Better integration with farm narratives and realistic savegames
- A future foundation for payroll-style labour management

The goal is not to change the Farming Simulator contract system itself, but to improve how AI worker payments are calculated and represented.

## Relationship with FS25_HelperProfiles

**FS25_HelperPayroll** is being developed as a companion mod to **FS25_HelperProfiles**.

Where HelperProfiles focuses on defining and managing helper identities, HelperPayroll focuses on how those helpers are paid.

Together, the two mods are intended to support a more immersive staffing model, where different helpers can have different roles, levels of experience, and wage expectations.

## Installation

Once a release build is available:

1. Download the latest `FS25_HelperPayroll.zip` release.
2. Place the zip file in your Farming Simulator 25 `mods` folder.
3. Enable the mod when loading your savegame.
4. If using **FS25_HelperProfiles**, enable both mods together.

Do not unzip the mod unless you are developing or testing changes.
