# HelperPayroll 0.4.4.0 Alpha 1

This pre-release changes the default way HelperPayroll measures worker time.

Previous builds primarily accounted worker hours from real frame time. **0.4.4.0 Alpha 1 uses Farming Simulator's in-game clock as the default authoritative time basis**, so deliberate in-game time acceleration now affects worker payroll.

This is an alpha pre-release for wider testing, not a stable release.

## Game-clock payroll

The default setting is now:

```xml
<workerTimeBasis>gameClock</workerTimeBasis>
<maxPayrollTimeScale>10</maxPayrollTimeScale>
```

With the default 10× billable cap:

| FS effective time scale | Billable payroll scale |
|---:|---:|
| 1× | 1× |
| 5× | 5× |
| 10× | 10× |
| 30× | 10× |
| 60× | 10× |
| 120× | 10× |
| 360× | 10× |

The **actual Farming Simulator effective time scale is still used for clock validation**. The payroll cap only limits billable wage acceleration; it does not make high-speed clock movement look invalid.

Set `maxPayrollTimeScale=0` to remove the cap and bill the full validated game-clock acceleration.

## Legacy real-time mode

Players who prefer the previous accounting model can select:

```text
workerTimeBasis = realTime
```

In `realTime` mode, worker wages accrue from real frame time rather than accelerated in-game time.

## Clock safety

Game-clock accounting now:

- stops accruing wages while the game clock is paused;
- supports coarse/batched environment clock updates;
- rejects and re-anchors implausible time jumps rather than charging them as labour;
- rejects clock rollback;
- rejects large sleep/period discontinuities;
- tracks both validated game-clock elapsed time and billable game-clock elapsed time;
- splits active `dailyPayroll` work across midnight so work is attributed to the correct game day.

## Billing UI and save data

The Billing tab now exposes:

- **Worker time basis** — `gameClock` or `realTime`;
- **Max payroll time scale** — default `10`, or `0` for unlimited.

Both values persist per savegame and are included in the generated/default policy configuration.

## API and diagnostics

The public API remains **version 5**. Existing public API methods are retained.

Payroll snapshot schema advances to **v4**. Active work can now expose:

- real elapsed hours;
- validated game-clock elapsed hours;
- billable game-clock elapsed hours;
- effective FS time scale;
- billable payroll time scale;
- configured payroll cap;
- rejected clock discontinuity count;
- active per-day work segments.

The runtime diagnostics and `getStatus()` also expose the current time basis and effective/billable scale information.

## HelperProfiles compatibility

HelperPayroll remains **optional** for HelperProfiles.

- **HelperPayroll owns:** payroll roles, pay rates, worker compensation overrides, wage accounting, settlement and payroll history.
- **HelperProfiles owns:** worker identity, roster availability and helper selection.
- HelperProfiles only consumes HelperPayroll's public payroll snapshot/API to display read-only role and live **COST** information.

Neither mod requires the other to run.

## Existing 0.4.3.0 Alpha 2 functionality retained

This build retains the current main-line features, including:

- A–T / twenty-worker HelperProfiles integration;
- roster-aware Workers filtering while preserving OFF-worker payroll data;
- external-worker session accounting, including AutoDrive continuity integration;
- live payroll Dashboard;
- WorkerCosts conflict protection;
- persistent ledger and daily payroll settlement;
- single-player authority boundaries prepared for later multiplayer work.

Multiplayer remains disabled in this release.

## Validation

Automated validation covers:

- XML parsing and Lua syntax;
- 1×, 5× and 10× game-clock accrual;
- 30×, 60×, 120× and 360× gameplay capped to 10× billing;
- unlimited cap mode;
- paused-clock behaviour;
- rejected large clock jumps and rollback;
- coarse/batched clock updates;
- midnight work splitting;
- legacy `realTime` mode;
- package construction.

This alpha is being published specifically to widen in-game testing of economic balance and clock edge cases before any stable promotion.
